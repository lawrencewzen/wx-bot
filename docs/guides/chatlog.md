# 聊天记录双向存档

wx-bot 的收件箱只解决了一半问题：它持久化的是**入站**事件（用户发来的消息），7 天后清理；而 Agent 的**回复**（`wx-bot send` 发出去的内容）无处可查。用户在 Agent 自己的聊天里问"微信里聊了啥"时，Agent 答不上来。

推荐做法：由 Agent 在每次处理完一条消息后，把这一问一答追加到按天切分的 Markdown 文件里，形成完整的双向存档。

## 存档格式

`chatlog/YYYY-MM-DD.md`（日期取事件的 `create_time`）：

```markdown
## 17:21 他
瑞幸有没有无糖无咖啡因的饮料

## 17:21 小八
有的，……
```

语音消息记转写文字（`voice_text`），图片/文件/视频注明类型和本地路径（`media[].path`）。

## 接入方式

在 Agent 处理消息的指令里加一条（以 Muse 的 hook prompt 为例，Grok routine / 其他 Agent 同理）：

> 每处理完一条消息事件，把这一问一答追加到 `chatlog/YYYY-MM-DD.md`（按事件日期）。
> 每个事件只记一次：用 `event_id` 去重，文件里已有就不重复写。

## 注意事项

- **去重**：同一事件可能投递多次（重投、租约过期），写文件前先按 `event_id` 检查是否已记录。
- **隐私**：存档文件和收件箱一样是敏感数据，权限设为仅自己可读，不要提交到公开仓库。
- **只记文本**：媒体文件本身已在 `media_dir` 落盘，存档里记路径即可，不用复制。
